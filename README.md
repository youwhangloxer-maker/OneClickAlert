# 원클릭 알림 (안드로이드 앱)

- **알림 버튼**: '딩동' 차임 → 0.8초 뒤 안내 음성(mp3) 재생 + 진동
- **주변 소리 듣기**: 폰 마이크 소리를 이어폰으로 실시간 전달 (음량 0~400%)
- **권한 설정 버튼**: 이 앱의 안드로이드 권한 설정 화면으로 바로 이동
- **안내 음성**: 기본 음성(`app/src/main/assets/guest-waiting.mp3`)이 들어 있고, 앱에서 mp3를 고르면 그 파일로 바뀜. "기본 음성" 버튼으로 되돌리기

## APK 만드는 방법 (GitHub, 무료)

1. github.com 에서 새 저장소(New repository)를 만듭니다. 공개/비공개 모두 됩니다.
2. 이 폴더의 파일을 전부 저장소에 올립니다 (Add file → Upload files, 폴더째 끌어다 놓기).
   - `.github` 폴더가 꼭 같이 올라가야 자동 빌드가 됩니다.
3. 저장소의 **Actions** 탭을 엽니다. 'APK 빌드'가 자동으로 돌기 시작하고 약 3~5분 걸립니다.
4. 초록색 체크가 뜨면 해당 실행을 눌러 맨 아래 **Artifacts**의 `OneClickAlert-apk`를 받습니다.
5. 받은 zip 안의 `OneClickAlert.apk`를 폰에서 열어 설치합니다.
   - '출처를 알 수 없는 앱 설치' 허용 창이 뜨면 허용해 주세요.

## Android Studio로 만드는 방법

이 폴더를 Android Studio에서 열고 **Build → Build APK(s)** 를 누르면 됩니다.

## 참고

- 하울링 방지를 위해 이어폰(유선/블루투스/USB)이 연결돼 있을 때만 주변 소리 듣기가 켜집니다.
- 블루투스 이어폰은 유선보다 소리가 조금 더 늦게 들립니다.
- 듣는 동안은 화면이 꺼지지 않게 유지됩니다.
